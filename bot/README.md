# Harmony VPN — Telegram-бот (Фаза 1 / MVP)

Бот для продажи VPN-подписок (VLESS Reality через Marzban) с оплатой картой,
криптой или Telegram Stars.

## Что уже работает
- `/start` — регистрация клиента, учёт реферала (`/start <telegram_id_пригласившего>`)
- `/buy` — выбор тарифа → выбор способа оплаты → оплата → автоматическая выдача
  ссылки на подписку (создаёт/продлевает пользователя в Marzban)
- Способы оплаты: ЮKassa, CryptoBot, Telegram Stars (каждый можно включить/выключить
  через .env — просто не заполняй соответствующие переменные)

## Что ещё предстоит (Фаза 3, см. roadmap в корневом README.md)
- `/my` — статус подписки, оставшийся трафик
- Детект аномального трафика, динамические акции, встроенный редактор
  конфигов Xray, мониторинг микросервисов

Реферальная программа, умные рассылки и тикеты поддержки (Фаза 2) уже
реализованы — команды: `/referral`, `/support`, админские `/referral_mode`,
`/referral_days`, `/referral_percent`, `/broadcast_add`, `/broadcast_list`,
`/broadcast_toggle`, `/broadcast_del`, `/reply`, `/close_ticket`.

## Важно
- Marzban распространяется под AGPL-3.0 — если дорабатываешь его исходники
  и даёшь клиентам пользоваться сервисом по сети, по букве лицензии нужно
  открывать свои изменения. Harmony (этот бот) — отдельный код, лицензии
  Marzban не касается, если ты не редактируешь сам Marzban.
- Способ проверки оплаты для ЮKassa/CryptoBot сейчас — кнопка "Я оплатил"
  (ручной поллинг). Для продакшена лучше добавить вебхуки — это в Фазе 2.

Инструкции по запуску (Docker Compose и вручную) — в корневом [README.md](../README.md),
чек-лист деплоя — в [docs/DEPLOYMENT.md](../docs/DEPLOYMENT.md).
